# 第 3 周：Ethereum 账户、交易与 Gas

本周回答的问题是：**Ethereum 如何把一条签名指令变成全网一致的状态变化？**

## 学习目标

完成本周后，你应当能够：

- 区分外部拥有账户（EOA）与合约账户；
- 读懂交易的 `from`、`to`、`value`、`input`、`nonce`、Gas 与状态；
- 解释 nonce 如何排序同一账户发出的交易并帮助防止重放；
- 区分 Gas limit、实际 Gas used、费用上限相关字段与最终实际费用；
- 在不连接钱包的情况下，比较普通 ETH 转账与合约调用。

## 核心概念

### 1. Ethereum 是账户化状态机

Ethereum 的全局状态包含账户。EOA 由私钥控制，可以发起交易；合约账户由代码控制，只会在收到调用后按代码执行。地址只是一项标识，不能单凭外观判断背后是谁，也不能保证该地址一定存在可执行代码。

### 2. 交易是经过签名的状态更新请求

普通转账的 `to` 指向另一个账户，`value` 表示转移的 ETH；合约调用通常还包含编码后的 `input` 数据。交易执行成功意味着状态按规则更新，失败交易也可能因执行消耗计算资源而产生费用。

### 3. Gas 是计算资源计量

Gas 衡量执行与存储操作消耗的计算资源，不等于 ETH。最终费用取决于实际使用的 Gas 和每单位 Gas 的实际价格。Gas limit 是发送者允许该交易消耗的上限，不等于最终一定消耗的数量。

### 4. 钱包是签名与交互工具

资产和合约状态记录在链上；钱包管理密钥、构造签名请求并展示链上数据。钱包界面可能隐藏复杂字段，也可能显示错误或诱导内容，因此签名前必须独立核对网络、目标地址、金额、调用方法和授权范围。

## 实践

本周先做只读研究，不要求创建钱包。使用 [Etherscan](https://etherscan.io/) 或其他 Ethereum 主网浏览器时，不连接钱包、不签名。

### 实践 A：比较 EOA 与合约账户

1. 选择一个有多笔普通转账的 EOA 和一个有已验证源码的知名合约地址。
2. 对两者分别记录余额、交易数量/nonce、是否存在代码、代币持仓展示。
3. 回答：浏览器把哪些内容直接从链上读取，哪些内容可能是浏览器维护的标签或解释？
4. 对合约记录代理标记（若有）、实现地址（若浏览器展示）和源码编译器版本。
5. 写下为什么“源码已验证”不等于“合约安全”。

### 实践 B：对比普通转账与合约调用

各选择一笔成功交易：

| 字段 | 普通 ETH 转账 | 合约调用 |
| --- | --- | --- |
| `from` / `to` |  |  |
| `value` |  |  |
| `nonce` |  |  |
| `input` |  |  |
| 状态 |  |  |
| Gas limit |  |  |
| Gas used |  |  |
| 实际费用 |  |  |
| 产生的事件日志 |  |  |

然后回答：哪一笔触发了合约代码？`value = 0` 是否意味着交易“什么也没做”？事件日志是否等同于合约当前状态？

### 实践 C：分析一笔失败交易

1. 在浏览器中找一笔状态为失败的合约交易。
2. 记录其 nonce、Gas limit、Gas used、费用和浏览器展示的失败原因。
3. 检查发送者是否仍支付了费用。
4. 区分“交易没有改变预期业务状态”和“交易没有消耗任何资源”。
5. 不依据浏览器的一句错误标签下最终结论；记录需要代码、调用轨迹或其他工具进一步确认的部分。

### 实践 D：Gas 纸面计算

使用你观察到的成功交易数据，按浏览器字段计算：

```text
实际交易费用 = Gas used × effective gas price
```

注意单位换算：`1 ETH = 10^18 wei`，`1 gwei = 10^9 wei`。将手算结果与浏览器结果核对，并说明为什么不能直接用 Gas limit 计算实际费用。

## 验收问题

1. EOA 和合约账户由什么控制？谁能主动发起顶层交易？
2. nonce 在同一 EOA 的交易中起什么作用？
3. `to` 是合约且 `value = 0` 时，交易仍可能做什么？
4. Gas、Gas limit、Gas used 和 ETH 费用分别是什么？
5. 为什么失败交易通常仍然产生费用？
6. 钱包卸载后，链上的资产是否消失？真正需要恢复的是什么？
7. 区块浏览器显示的项目名称标签为什么不能被当作共识数据？

判断标准：能够从具体交易字段还原“谁请求执行什么、执行是否成功、用了多少资源”，且不把钱包、浏览器或 EOA 与链上资产混为一谈。

- 本周所有任务均不需要连接钱包；任何要求签名才能查看公开交易详情的网站都应被视为异常。
