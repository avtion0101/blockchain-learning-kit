# 区块链新手学习与研究工具包

这是一套面向零基础学习者的 10 周自学材料。目标不是记住币种和术语，而是建立一套能够独立解释机制、验证事实、识别信任假设和研究协议的方法。

## 从这里开始

1. 阅读本页的安全边界与学习方法。
2. 阅读 [`FOUNDATIONS.md`](./FOUNDATIONS.md)，建立第一张完整的概念地图。
3. 打开 [`curriculum/`](./curriculum/) 按周学习，每周完成其中的交付物和验收题。
4. 第 1 周运行 [`labs/foundations/`](./labs/foundations/) 中的密码学与玩具账本实验。
5. 第 2～4 周使用 [`labs/explorers/`](./labs/explorers/) 的观察表拆解真实交易。
6. 第 5～6 周完成 [`labs/points-contract/`](./labs/points-contract/) 的 Solidity 积分合约实验。
7. 第 7～10 周使用 [`research/`](./research/) 中的模板完成第一份协议研究报告。
8. 每周在 [`PROGRESS.md`](./PROGRESS.md) 记录证据，而不是只勾选“看过”。

## 你最终要获得的能力

- 用自己的话解释哈希、签名、交易、区块、节点、共识与最终性。
- 分别拆解一笔 Bitcoin UTXO 交易和一笔 Ethereum 状态转换。
- 区分钱包、私钥、地址、节点、交易所、合约与区块浏览器。
- 编写并测试一个只允许所有者增发的最小积分合约。
- 画出协议的资金流、信息流、控制权与外部依赖。
- 依据规范、代码、链上数据和治理记录提出可证伪的研究结论。

## 建议节奏

每周安排 6～8 小时：

- 2 小时：阅读官方材料并整理概念。
- 2～3 小时：完成动手实验或链上观察。
- 1 小时：不看资料，用自己的话复述。
- 1～2 小时：完成验收题、修正错误并记录证据。

遇到不理解的概念时，先尝试回答四个问题：

1. 它要解决什么问题？
2. 谁生成信息，谁验证信息？
3. 哪些规则必须由所有节点一致执行？
4. 如果某个参与者作恶，会发生什么？

## 快速运行本地实验

本机安装 Node.js 22.13.0 或更高版本后，可在本目录运行：

```powershell
npm run test:foundations
npm run demo:crypto
npm run demo:ledger
```

智能合约实验首次运行前，先进入 `labs/points-contract/` 执行 `npm install`；之后可回到本目录运行 `npm run test:contract`。完整说明和安全边界见该实验自己的 README。

## 安全边界

- 全部练习只使用本地模拟环境或公开测试网，不需要购买任何代币。
- 学习钱包与真实资产钱包必须分开；不同环境不要复用助记词或私钥。
- 助记词、私钥、密钥库文件和签名请求不得发送给他人或粘贴到陌生网站。
- 测试网代币没有投资价值。任何索要付款、保证收益或声称可以恢复私钥的人都应视为高风险。
- 示例合约只用于教学，未经独立审计，不得用于管理真实资产。
- 本工具包用于技术教育与研究训练，不构成投资、法律或税务建议。

## 材料结构

```text
blockchain-learning-kit/
├── curriculum/           # 10 周逐周课程
├── labs/
│   ├── foundations/      # 哈希、签名、区块链和 UTXO 实验
│   ├── explorers/        # Bitcoin / Ethereum 交易观察表
│   └── points-contract/  # Solidity 合约与自动化测试
├── research/             # 协议研究和证据记录模板
├── checklists/           # 能力与安全检查清单
├── FOUNDATIONS.md        # 区块链核心机制与常见误解
├── GLOSSARY.md           # 新手核心术语表
├── RESOURCES.md          # 一手资料阅读入口
└── PROGRESS.md           # 10 周进度与证据记录
```

## 完成标准

“完成”不是看完链接。每周至少要留下一个可检查的产物：命令输出、填写完成的观察表、概念图、测试结果、研究笔记或口头复述稿。到第 10 周，用 `checklists/` 的最终清单做闭卷验收；不会的部分回到对应周重做实验。
