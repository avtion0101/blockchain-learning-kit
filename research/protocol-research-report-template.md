# 协议研究报告模板

> 用途：完成一份可复核的 3～5 页协议研究报告。先写研究问题，再收集证据；不要从币价或“看好/看空”开始。
>
> 重要声明：本模板用于技术与研究训练，不构成投资建议、交易建议或收益承诺。不要因为完成本报告而投入真实资金。

### 结论标签约定

- **事实**：可由原始资料、代码或链上数据直接核验。
- **推断**：从事实推导出的解释，必须写出推理过程。
- **假设**：尚未获得充分证据、等待验证的判断。

全文中的关键判断请标注【事实】、【推断】或【假设】，避免把观点写成事实。

## 12. 证据与复核

使用 [证据记录表](./evidence-log-template.md)保存每条关键证据。证据优先顺序：

> 协议规范与代码 → 链上原始数据 → 审计与漏洞记录 → 治理提案 → 官方文档 → 高质量独立研究 → 媒体与社交平台

最低复核要求：

- [ ] 每个关键结论至少关联一个证据编号
- [ ] 安全、权限和资产流结论至少有一项原始资料支持
- [ ] 已记录访问日期、版本、网络和区块高度
- [ ] 已区分“已上线”“已接受但未上线”“提案”“讨论”
- [ ] 已主动搜索并记录反证
- [ ] 数据查询或计算可以由另一人复现
- [ ] 过期、失效或相互矛盾的来源没有被静默忽略
