# 链上数据问题工作表

> 用途：把一个模糊的项目判断，转化为可复现的链上数据问题。一次只研究一个问题；先锁定口径，再看结果。
>
> 重要限制：链上地址不等于自然人，交易量不等于真实需求，TVL 不等于可安全退出的资产。本工作表用于研究训练，不构成投资建议。

## 0. 选择一个问题

可从以下示例中选择，也可自拟：

- [ ] 活跃使用是否持续增长，而不是短期激励或机器人造成？
- [ ] 协议收入是否来自真实使用，而不是代币补贴或自成交？
- [ ] 流动性是否集中在少数地址、池或资产？
- [ ] 大额用户同时退出时，协议是否有足够可用流动性？
- [ ] 治理权、管理员权或代币是否高度集中？
- [ ] 跨链后的资产是否得到足额、可赎回的支持？
- [ ] 自拟：【填写】

## 1. 把问题写成可验证形式

### 1.1 原始问题

【例如：“这个协议真的有人用吗？”】

### 1.2 可验证问题

【例如：“在 2026-04-01 至 2026-06-30，剔除已知机器人、路由合约和同地址往返交易后，每周独立交互地址和新地址 4 周留存率是否连续两个自然月上升？”】

### 1.3 预先写下判断规则

- 若【指标】达到 / 超过【阈值】并持续【时间】，则支持假设。
- 若【指标】低于【阈值】或出现【反向现象】，则反对假设。
- 若【数据缺失 / 口径冲突 / 样本不足】，则结论为“无法判断”，而不是勉强下结论。

- H0（替代解释或反假设）：【填写】
