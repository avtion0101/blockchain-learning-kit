# 研究工具使用说明

这组模板用于第 9～10 周的链上分析和协议研究。请先复制模板再填写，保留原文件作为干净母版。

## 推荐使用顺序

1. 打开 [协议研究报告模板](./protocol-research-report-template.md)，先填写研究问题、范围、网络、版本、日期和区块高度。
2. 从研究开始就使用 [证据记录表](./evidence-log-template.md)，为事实、推断、支持证据和反证分配编号。
3. 使用 [信任、资金与控制流绘图模板](./trust-and-fund-flow-template.md)，画清资产、信息、权限、外部依赖及失败路径。
4. 涉及用户、收入、流动性或集中度时，使用 [链上数据问题工作表](./onchain-data-question-worksheet.md)锁定指标口径并保存复现步骤。
5. 回到报告模板，引用证据编号、图和数据结果，完成风险、反证与结论失效条件。

## 如何复制

- 为每个协议建立独立工作文件夹，将四个模板一起复制进去；保持原文件名可使模板间链接继续有效。
- 若重命名文件，请同步更新文档中的相对链接。
- 不要覆盖模板，也不要在文件中保存私钥、助记词或 API 密钥。
- 每次协议升级、治理变更或重新取数后，更新报告版本、核验日期和区块高度。

完成报告后，使用 [最终能力自测](../checklists/final-capability-self-check.md)验收。所有材料仅用于学习与研究，不构成投资建议。
