# 区块浏览器观察实验

本目录的工作表用于训练“从原始记录推导结论”，不是教你依赖某一个浏览器品牌。

## 使用顺序

1. 先从相应官方资料入口找到当前可用的区块浏览器。
2. 任选近期区块和普通交易，不连接钱包也能完成大部分观察。
3. 将交易链接、区块高度和观察日期写入工作表。
4. 每个结论注明对应字段；无法从页面验证的内容写成“未知”，不要猜测。
5. Ethereum 写操作只使用专用学习钱包和当前推荐的应用开发测试网。

- [`bitcoin-observation.md`](./bitcoin-observation.md)：UTXO、输入、输出、手续费与确认。
- [`ethereum-observation.md`](./ethereum-observation.md)：账户、Gas、输入数据、事件与状态变化。
