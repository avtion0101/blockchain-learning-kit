## 基本字段

| 项目 | 观察值 | 它说明什么 |
|---|---|---|
| 状态 |  | 交易执行成功还是回滚 |
| From |  | 谁的密钥授权了交易 |
| To |  | 普通账户或合约地址 |
| Value |  | 随交易转移的原生资产 |
| Nonce |  | 发送账户的交易序号 |
| Gas limit |  | 发送者允许的执行量上限 |
| Gas used |  | 实际消耗的执行量 |
| Effective gas price |  | 每单位 Gas 的实际价格 |
| Transaction fee |  | 实际支付的网络费用 |
| Input data |  | 空、普通数据或合约调用编码 |
